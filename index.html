A personal assistant for everyday administration.

Nadav Personal Agents is a privately operated desktop system that helps its owner review communications, see calendar commitments, and catalog personal documents.

What the Google connection does

Mail
Reads selected personal messages to prepare summaries, identify follow-ups, and surface bills or delivery updates.
Calendars
Reads approved primary calendars to show commitments and possible overlaps. A separate calendar-only connection does not grant access to that account’s mail or files.
Files & contacts
Lists personal Drive file metadata for a catalog and reads authorized contact details to support personal organization.

Controlled by the owner

Current Google integrations are read-only. The assistant does not send mail, change calendar events, download attachments, or modify Drive files through these integrations. New permissions require a separate authorization.

Selected source data is processed by OpenAI services to produce the owner’s requested assistance. Read the privacy notice for details.

About this page

This is an information page for the OAuth application. The assistant is for the owner’s personal use and is not offered for public registration.
