Privacy notice · Updated 3 November 2026

How information is used.

Nadav Personal Agents is operated by Nadav Lorber for his own personal use. This notice describes the current read-only Google integrations and this information website.

Information accessed

With the account owner’s consent, the application can read personal Gmail messages and message metadata, events from approved primary calendars, personal Google Drive file metadata, and authorized contact details. It uses account identity information to verify the connected account. A separately authorized calendar-only account provides primary-calendar events and identity verification only; its mail, contacts and files are excluded.

The current integrations do not send messages, change calendars, download email attachments, or edit or delete Drive files. Google sign-in and consent take place through Google’s authorization flow. The application does not ask for or store the owner’s Google password.

Purpose and AI processing

Information is used to prepare personal briefings, summarize selected mail, highlight commitments and follow-ups, and maintain a document metadata catalog. Selected source content and relevant context are sent to OpenAI services through the owner’s configured ChatGPT/Codex connection to generate the requested assistance. OpenAI’s applicable service terms, privacy policies, retention and account data controls also apply to that processing.

This application does not sell Google user data, use it for advertising, or use it to assess creditworthiness. Use of information received from Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and access

OAuth credentials are kept in protected local credential stores on the owner’s Windows PC. Working records, catalogs, conversation history and generated reports are stored in the owner-controlled runtime. Selected data can also be retained in the owner’s backups and by the processing services under their applicable terms. Access to the assistant’s dashboard is restricted to the owner’s private access setup. This public information website does not receive Google account data.

Retention and removal

There is currently no automatic retention period for local records and reports. The owner can stop scheduled processing, revoke the app’s Google access, and delete local records or backups. Revoking access stops future authorized retrieval but does not automatically remove existing reports, backups or provider-held records. Provider-held information is managed through that provider’s applicable account controls and policies.

Google access can be reviewed or revoked in Google Account connections.

This website

These static information pages contain no sign-in form, analytics script, advertising or tracking code added by the application. When hosted on GitHub Pages, GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. Following an external link takes you to that service and its own privacy practices.

Changes and contact

This notice will be updated if the application’s data practices change. Additional Google permissions require a new consent flow. Contact the operator through Nadav Lorber’s LinkedIn profile.
